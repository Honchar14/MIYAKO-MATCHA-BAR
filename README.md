# MIYAKO — Matcha Bar

Лоадер и первый экран сайта матча-бара MIYAKO: персонаж взбивает матчу, бежит к краю и вытягивает главный экран; живой фон бара, побуквенные «барабаны» с японским, рукописное появление текста, кастомный курсор.

- `index.html` — разметка и стили первого экрана
- `loader.js` — вся анимация (GSAP 3.12.5 с CDN)
- `assets/` — фон (видео + постер), флаеры, персонаж, клипы и кадры анимации, SVG

Сборки нет — это статический сайт. Локально: `npx serve .` или любой статический сервер.
